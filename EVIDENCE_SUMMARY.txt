### For Reviewers

2. Check the claim category: [MEASURED], [VERIFIED], [DESIGNED], [PLANNED], or [DESIGNED BUT BROKEN]
3. Click the evidence link
4. Verify the claim against the evidence

### For Developers Modifying Performance
1. Run `cargo run --release --bin measure_evidence`
2. Compare new measurements to `docs/demo_evidence/csv/latency_measurements.csv`
3. If latency changed:
   - Update `docs/demo_evidence/` with new measurements
   - Update EVIDENCE.md category (e.g., [DESIGNED] → [MEASURED])
   - Commit both old and new evidence
   - Document the change

### For Claims Without Evidence
If you're tempted to claim something:
1. Implement it
2. Measure it with `measure_evidence`
3. Save to `docs/demo_evidence/`
4. Link from EVIDENCE.md
5. Commit together
6. Only then document the claim
