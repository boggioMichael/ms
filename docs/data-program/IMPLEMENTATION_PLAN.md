## P1 — what was proven (§16 P1, §17)

observation → help request → correction → outcome → Episode → sanitized local export → report, on
synthetic participants only (`game_id "synthetic"`, generated by `research::synthetic`; no real user data
in Git). Each row is a test in `tests/research_slice.rs` that passed:

- consent off → no recorder is made, nothing is written, no folder is created; the module holds no network
  code (a source scan: no sockets, no curl, no `Command`);
- withdrawal with a batch pending cancels it; an expired rights policy refuses (at open, while recording,
  at export); an export for a purpose or recipient not consented or not licensed is refused — MapleStory
  and MapleStory Worlds data refused even with full consent;
- no character name, chat line or credential reaches any written file; no original id survives into an
  export; in-game text that reads like an order is kept as `untrusted_text`, never obeyed;
- duplicate and out-of-order events build the same episode; `unknown` never becomes 0; `model_inferred`
  never becomes `human_reviewed` or gold; a poisoned correction is kept as a claim, not applied;
- deleting a research subject removes their events, episodes and export rows and lists the exports it
  touched (lineage);
- the manifest's SHA-256 per file matches, and the loader verifies it (a changed byte: refused, exit 2).

A run of the example: 48 events from three consenting synthetic participants (a fourth never consents —
nothing of theirs is written), 5 episodes, an export of 41 events from 2 participants (7 rows of the one
who consented only to improving Syrup left out and counted), the buyer and media exports refused, and a
first report (M1.1–M1.5 with numerators, denominators and participant counts, marked SYNTHETIC and
"insufficient evidence").
