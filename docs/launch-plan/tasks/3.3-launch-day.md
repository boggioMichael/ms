- **פרסום:** Actions → MapleSyrup standalone → Run workflow על התג, עם publish מסומן ושורה על מה חדש (היא מופיעה בטלפון). ההרצה בונה מחדש מהתג (עד שעה), מחליפה את קבצי הטיוטה, הופכת אותה לציבורית ושולחת את הקבצים לאתר. לכן מתחילים ב-19:00, ובודקים את מה שפורסם לפני הפוסטים.
- **hotfix:** ענף מהתג, תיקון אחד, גרסה חדשה (מספר פאץ׳), אותו workflow. העדכון האוטומטי מביא אותו לכל השחקנים.
