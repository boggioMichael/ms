# תכנית ההשקה של MapleSyrup

> **עודכן ב-ו׳ 9.10.2026:** כל התכנית נדחתה בשבוע, וההשקה עברה ל-**ד׳ 28.10 ב-21:00** שעון ישראל. המשימות חולקו מחדש לפי הזמן שיש לכל אחד, ומה שלא הכרחי להשקה נדחה. [מה השתנה](#מה-השתנה-ב-910)

## בקצרה

- **ד׳ 21.10:** MapleStory Classic World נפתח לכולם. באותו ערב יוצאים פוסטי הבטא, כשכולם מחפשים כלים.
- **א׳ 25.10:** הקפאת קוד. מכאן נכנסים רק תיקוני P0.
- **ד׳ 28.10, 21:00:** MapleSyrup יוצאת לציבור (19:00 UTC, 12:00 בחוף המערבי של ארה״ב).
- **ה׳ 5.11:** רטרו ותכנית לנובמבר–דצמבר.

## איפה המשימות שלי

לכל משימה יש **Issue ב-GitHub** עם התווית `launch-plan`, ובו רשימת תתי־משימות: ליד כל שורה מי אחראי ועד מתי. **ה-README של המשימה** (בטבלה למטה) מסביר למה היא חשובה, מתי היא גמורה, איך עובדים ואילו קבצים לפתוח.

- [**המשימות הפתוחות שלי**](https://github.com/boggioMichael/ms/issues?q=is%3Aissue%20is%3Aopen%20label%3Alaunch-plan%20involves%3A%40me): קישור אחד ששווה לשמור. הוא מראה כל Issue שמשויך אליך או מזכיר אותך.
- **התראות:** GitHub שולח מייל כשמשייכים אותך למשימה או מזכירים אותך (@). אפליקציית GitHub בטלפון שולחת גם התראה. כדאי לוודא שבהגדרות, ב-Notifications, המייל פעיל ל-Participating.
- **בלי Slack:** כל מה שצריך בשביל המשימות נמצא כאן וב-Issues.

### איך מעדכנים

- **התחלת:** תגובה קצרה ב-Issue ("התחלתי 1.2.4").
- **גמרת:** ✓ ליד תת־המשימה ב-Issue.
- **תקוע, או שלא תספיק עד התאריך:** תגובה ב-Issue עם @boggioMichael, באותו יום. עדיף להגיד מוקדם; לכל משימה יש סעיף "אם אין זמן" שאומר על מה אפשר לדלג.
- **PR:** בתיאור `Part of #<מספר ה-Issue>`, או `Closes #<מספר>` אם הוא סוגר את כל המשימה.
